## Run locally

Copy the poster into the output directory (defaults to `/output`) using Node 22:

```bash
node main.ts
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

To regenerate the artwork itself with Pillow:

```bash
/data/workspace/commons-demo/.venv/bin/python generate_entry.py
```
